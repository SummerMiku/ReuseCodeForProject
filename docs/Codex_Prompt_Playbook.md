# 可复用请求

## 勘察

```text
先只读AGENTS.md、当前状态和相关设计/源码。
核对真实基线、入口、数据流、现有测试与未知项。
给出风险和一个范围明确的下一票据建议。
```

## 起草票据

```text
为<目标>起草下一张票据，先不要实施。
包含批准/待定规则、依赖、允许路径、非目标、验收标准、验证和回滚方案。
按现有索引分配ID；不得把未来需求放进本票。
```

## 执行已批准票据

```text
已批准执行<TICKET_ID>。
读取规则、当前状态、票据与有关源码，按票据范围完成实现和必要验证。
已有授权无需反复确认；新产品规则或范围改变时先给出具体选项。
结束时更新报告，区分实现、验收、main集成和运行交付。
```

## 审查

```text
依据票据和真实完整diff进行只读审查。
报告可定位的功能/数据/架构/回归问题，给出证据、影响和建议。
检查未执行验证与文档漂移；不要直接扩展实现范围。
```

## 交接

```text
更新Current_State和当前票据context/tasks/report。
记录准确分支/提交、未提交内容、批准决定、完成与未完成、测试产物和精确下一步。
新会话据此继续，不依赖全部聊天记录。
```
